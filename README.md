# Wallet Tracker

## Overview
Wallet Tracker is an application designed to help users manage their cryptocurrency wallets efficiently. It provides various functionalities to track balances, transactions, and performance across different assets.

## Features
- **View Balances**: Easily view your total wallet balance across all currencies.
- **Transaction History**: Keep track of your buy/sell transactions.
- **Performance Metrics**: Gain insights into the performance of your investments over time.

## Installation
To install Wallet Tracker, follow these steps:
1. Clone the repository:
   ```bash
   git clone https://github.com/eslammohamedr/WalletTracker.git
   ```
2. Navigate to the project directory:
   ```bash
   cd WalletTracker
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

## Usage
To start using the Wallet Tracker:
1. Run the application:
   ```bash
   npm start
   ```
2. Follow the guided instructions on the web interface.
