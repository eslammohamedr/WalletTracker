# Wallet Tracker

## Overview
Wallet Tracker is an  android application designed to help users manage their  wallets efficiently. It provides various functionalities to track balances, transactions, and performance across different assets, also it use AI to help automatically add records for your payments.

## Features
- **View Balances**: Easily view your total wallet balance across all currencies.
- **Transaction History**: Keep track of your buy/sell transactions.
- **Performance Metrics**: Gain insights into the performance of your investments over time.
- **AI**: Parse incoming sms and analyze it using AI to add records automatically.
- **Authintication**: To save the data on the account .
   

## Installation
To install Wallet Tracker, follow these steps:
1. Clone the repository:
   ```bash
   git clone https://github.com/eslammohamedr/WalletTracker.git
   ```
2. Navigate to the project directory:
   ```bash
   cd WalletTracker
   ```
3. Build the app with android studio

4. install the APK on your phone
